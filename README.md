# Cumre Inmobiliario

Landing estático en HTML y CSS, sin JavaScript, dependencias ni compilación.

## Ver la página
Abre `index.html` con doble clic en tu navegador. También puedes usar Live Server en Visual Studio Code.

## Editar
- `index.html`: textos, contacto, secciones e iconos SVG integrados.
- `styles.css`: diseño y adaptación a celulares.
- `images/`: fotografías.
- `favicon.svg`: icono del sitio.

## Publicar gratis en GitHub Pages
1. Sube estos archivos a la rama `main` del repositorio público `rub3nrom3ro/CumreLanding`.
2. En Settings > Pages > Build and deployment, selecciona Deploy from a branch.
3. Selecciona main y /(root), y pulsa Save.
4. GitHub mostrará el enlace cuando termine de desplegar.

No se requiere npm, Node.js, React, Vite ni un flujo de compilación personalizado.
GitHub puede mostrar su tarea interna de despliegue: no compila esta aplicación.
Las rutas relativas permiten usar el dominio propio o /CumreLanding/.
Para actualizar, edita los archivos y sube los cambios a main.
